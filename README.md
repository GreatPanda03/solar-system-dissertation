## *An Application to Simulate Solar Systems, Orbitals, and Planetary Properties*


## About the Repository

#### Introduction
This repository tracks the development of my project, **"An Application to Simulate Solar Systems, Orbitals, and Planetary Properties"**. The project enables users to view a fairly accurate model of our solar system based on real data. Additionally, users can create custom solar system simulations with different bodies, such as stars, planets, and moons.

#### Commits
This repository contains the source code for the project. Occassional commits with source code have been provided. Each commit details new features, changes, and removals to the application. It also contains documentation for the application, such as its features and how to use it, provided in the Wiki section.

There are many commits from an account called **GreatPanda3**: this is myself, and is the account I have linked to Unity.

## Installing the Application

#### Download the `.zip` Folder
* **1)** Find and download the `Application.zip` folder within the repository
* **2)** Unzip the contents of the `.zip` file onto your Desktop *(or another appropriate location)*
* **3)** Within the `Application` folder in the `.zip` file, locate and open the application called `Solar System Maker`
* **4)** The application will start running on an available monitor and may take up the whole screen

#### Other Points
Unity / Unity Hub isn't necessary to install since the application is standalone with all required frameworks and libraries included with it.

If you encounter any issues with the application, or you'd like to view and edit the application yourself, you can import the application to Unity Hub.

**Unity Hub Download Page:** https://unity.com/download
